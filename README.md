# ClassPilot 班主任工作台

ClassPilot 是一个面向班主任的本地优先班务管理工具。第一版运行在 Windows 10/11，通过轻量启动程序打开 Web 界面，数据保存在工作台目录内的 SQLite 数据库中，无需登录，也无需连接互联网。

## 当前状态

项目处于设计阶段，尚未开始功能开发。

当前已确定：

- 产品形态：本地优先、离线可用的 Web 工作台
- 首发平台：Windows 10/11，支持 Microsoft Edge 和 Google Chrome
- 前端方向：React + TypeScript
- 本地服务：Go
- 数据存储：SQLite
- 数据组织：一个当前班级，可归档和查看历史班级
- 第一阶段：班级基础底座

## 数据安全

真实学生资料、数据库、附件、导入文件、导出文件、备份和本地日志不得提交到 Git 仓库。仓库仅保存源代码、测试、公开示例和项目文档。

## 开发约定

- README、设计文档和实施计划使用中文。
- Git 提交信息使用中文。
- 先完成设计与实施计划评审，再开始编码。
- 每个阶段都需要验证数据安全、导入导出和备份恢复能力。
