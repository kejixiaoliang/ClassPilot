# ClassPilot 第一阶段“班级基础底座”设计规格

## 1. 设计目标

第一阶段交付一个可离线使用的班级信息管理底座。班主任可以创建当前班级，导入并维护学生资料，保存头像和附件，打印或导出名单，备份和恢复数据，并将完成使用的班级归档。

完成标准是：用户在没有互联网、没有账号和没有预装开发环境的 Windows 10/11 电脑上，可以通过轻量启动程序完成上述工作。

## 2. 技术架构

### 2.1 总体结构

```text
React + TypeScript Web 界面
            ↓ 本地 HTTP API
      ClassPilot.exe（Go）
            ↓
SQLite 数据库 + 本地附件与备份
```

### 2.2 职责边界

#### Web 前端

- 页面展示和交互
- 表单校验和导入预览
- 列表查询条件管理
- 打印页面排版
- 调用统一业务 API

前端不得直接依赖 SQLite、Windows 绝对路径或本地文件系统。

#### Go 本地服务

- 仅监听 `127.0.0.1`
- 启动后打开默认浏览器
- 提供班级、学生、字段、附件、导入导出和备份 API
- 执行权限边界检查和服务端数据校验
- 管理 SQLite 事务与结构迁移
- 管理相对路径、附件复制和备份压缩
- 防止同一工作台目录被重复写入
- 关闭工作台后安全退出

#### SQLite

- 保存班级、学生、字段定义、字段值、附件索引和操作记录
- 使用稳定内部标识关联业务数据
- 使用外键、唯一约束和事务保证一致性
- 保存数据库结构版本

## 3. 页面与导航

```text
班主任工作台
├─ 工作台首页
├─ 当前班级
│  ├─ 班级概览
│  ├─ 学生名单
│  ├─ 学生详情
│  └─ 字段设置
├─ 数据中心
│  ├─ 批量导入
│  ├─ 数据导出
│  ├─ 备份与恢复
│  └─ 操作记录
├─ 历史班级
└─ 设置
```

### 3.1 工作台首页

- 显示当前班级名称、学段、年级和学年
- 显示学生总数及基础统计
- 显示最近修改的学生
- 显示最近成功备份时间
- 显示数据安全提醒
- 提供添加学生、导入名单和导出备份快捷入口

### 3.2 班级概览

- 编辑班级名称、学段、年级、学年和备注
- 展示班级创建时间和最近更新时间
- 发起班级归档

### 3.3 学生名单

- 表格视图和卡片视图
- 按姓名、学号和自定义字段查询
- 组合筛选与排序
- 单个新增、编辑和移入回收站
- 批量编辑可安全统一修改的字段
- 选择显示列
- 打印基础学生名单

### 3.4 学生详情

- 基本资料
- 联系与家庭信息
- 学籍与班级信息
- 自定义字段
- 头像与附件
- 数据变更记录

身份证号、电话和家庭信息等敏感字段默认遮挡，用户主动操作后显示。

### 3.5 字段设置

- 创建文本、长文本、数字、日期、单选、多选和布尔字段
- 设置字段名称、说明、是否必填、默认值和显示顺序
- 停用字段而不删除历史数据
- 核心字段不可删除，可调整是否在列表中显示

### 3.6 数据中心

- 导入 Excel、JSON 和 CSV
- 导入前预览字段映射、校验错误和重复冲突
- 导出 Excel、JSON 和 CSV
- 创建完整 SQLite 备份
- 创建包含数据库与附件的工作台备份包
- 恢复备份前校验版本和完整性
- 查看关键数据操作记录

### 3.7 历史班级

- 查看已归档班级
- 历史班级默认只读
- 导出历史班级数据
- 经明确确认后恢复为当前班级
- 同一时间只允许一个当前班级

## 4. 核心数据模型

### 4.1 班级

核心属性包括内部标识、班级名称、学段、年级、学年、状态、备注、创建时间、更新时间和归档时间。

班级状态分为“当前”和“已归档”。数据库约束同一工作台最多存在一个当前班级。

### 4.2 学生

核心属性包括内部标识、所属班级、姓名、性别、学号、出生日期、入班日期、状态、备注、创建时间和更新时间。

年龄由出生日期动态计算，不作为独立事实字段长期保存。学号允许为空；非空时在同一班级内保持唯一。

### 4.3 自定义字段

字段定义与字段值分开保存。字段定义归属于班级，可设置类型、必填状态、显示顺序和启停状态。停用字段保留原有字段值。

### 4.4 附件

数据库保存附件内部标识、所属学生、业务类型、原始文件名、相对路径、文件大小、内容类型、校验值、说明和创建时间。

附件文件复制到工作台 `attachments/` 目录，数据库不得保存仅在原电脑有效的绝对路径。

### 4.5 操作记录

记录导入、批量修改、删除、恢复、归档、备份和数据迁移等关键操作。操作记录用于问题追踪，不代替数据库备份。

## 5. 导入流程

1. 用户选择 Excel、JSON 或 CSV 文件。
2. 系统读取文件，但不立即写入数据库。
3. 用户确认列与系统字段、自定义字段的映射。
4. 系统校验必填项、数据类型、重复学号和文件格式。
5. 页面分别展示可导入数据、警告和错误。
6. 用户为重复数据选择跳过、更新或作为新记录导入。
7. 系统自动创建导入前备份。
8. 服务端在单个数据库事务中完成导入。
9. 导入失败时完整回滚，并保留错误报告。
10. 导入成功后生成操作记录和结果摘要。

JSON 导入分为“学生业务数据”和“ClassPilot 完整数据包”两种明确格式，避免把普通数据导入与灾难恢复混为一谈。

## 6. 导出与打印

### 6.1 业务导出

- Excel：适合教师继续编辑和交换名单
- CSV：适合通用表格工具
- JSON：保留结构化字段和系统标识，适合迁移与程序处理

导出时由用户选择字段和数据范围。默认不导出已移入回收站的学生。

### 6.2 完整备份

- `.sqlite` 数据库备份用于快速完整恢复
- 工作台备份包包含数据库和附件
- 备份文件名包含工作台名称、班级名称和生成时间
- 备份写入完成后执行完整性检查

### 6.3 打印

第一阶段提供基础学生名单打印，支持标题、显示列、纸张方向和打印日期。复杂模板编辑器不属于第一阶段。

## 7. 删除、归档与恢复

- 删除学生默认移入回收站
- 回收站记录不参与默认查询和统计
- 用户可以恢复学生
- 物理删除需要二次确认，并在执行前创建备份
- 班级归档后默认只读
- 恢复历史班级为当前班级时，必须先处理已有当前班级

## 8. 数据目录与升级

```text
ClassPilot/
├─ ClassPilot.exe
├─ data/
│  └─ classpilot.sqlite
├─ attachments/
├─ imports/
├─ exports/
├─ backups/
└─ logs/
```

- 程序首次启动时创建缺失目录
- 程序升级不得覆盖业务数据目录
- 启动时检测数据库结构版本
- 迁移前自动备份数据库
- 迁移失败时停止业务写入并提示恢复
- 日志不得记录完整敏感字段和附件内容

## 9. 异常处理

- 表单错误在字段附近显示明确原因
- 导入错误提供可下载的行级错误报告
- 文件被占用、空间不足和附件丢失时给出可执行的处理建议
- 数据库忙或写入失败时不得伪装为保存成功
- 未捕获错误写入脱敏本地日志，并向用户显示错误编号
- 数据库完整性检查失败后进入只读保护模式
- 任何恢复操作不得直接覆盖当前数据，必须先创建恢复前备份

## 10. 安全边界

- 第一版不设置启动密码，也不加密数据库
- 数据安全依赖 Windows 账户和目录权限
- 本地服务仅监听回环地址，不允许局域网访问
- 启动时生成临时访问令牌，浏览器请求必须携带令牌
- 上传文件校验大小、扩展名和内容类型
- 页面展示用户输入时执行转义，防止脚本注入
- Git 忽略真实数据库、附件、导入、导出、备份和日志

## 11. 测试与验收

### 11.1 自动测试

- 数据模型约束和数据库迁移测试
- 学生增删改查与回收站测试
- 自定义字段类型和校验测试
- Excel、JSON、CSV 导入映射及事务回滚测试
- 导出内容和字符编码测试
- 附件相对路径及校验值测试
- 备份、完整性校验和恢复测试
- API 参数校验及本地访问边界测试

### 11.2 端到端场景

1. 在空目录首次启动并创建班级。
2. 导入一份包含错误和重复数据的学生名单。
3. 修正映射后成功导入。
4. 新增学生、自定义字段、头像和附件。
5. 查询、筛选、打印并导出名单。
6. 删除并恢复学生。
7. 创建完整备份，在新的工作台目录中恢复。
8. 归档当前班级并验证只读行为。
9. 在断网环境重复核心流程。
10. 程序升级后验证原数据库和附件完整。

### 11.3 第一阶段验收标准

- 核心流程无需联网
- 刷新或关闭浏览器不丢失数据
- 整个工作台目录复制到另一位置后可正常启动
- 导入失败不会留下部分写入
- 数据库和附件可通过备份完整恢复
- 页面和打印结果正确显示中文
- 真实业务数据不会被 Git 跟踪
- Windows 10/11 的 Edge 和 Chrome 均可完成核心流程

## 12. 后续阶段接口预留

班级和学生使用稳定内部标识。座位、值日、考勤、奖惩、谈话、家校沟通和成绩模块只通过这些标识建立关联，不把姓名或学号作为永久关联键。

第一阶段只保留清晰的数据边界，不创建空业务表和不可验证的未来功能。
