# ClassPilot 班主任工作台产品总体规划

## 1. 产品定位

ClassPilot 是面向单个班主任的本地优先班务管理工作台。第一版服务于单台 Windows 电脑，用户无需注册登录，断网时仍能完成全部核心工作。

产品使用“便携式工作台目录”管理程序和数据。用户可以复制、压缩或归档整个目录，从而完成换机迁移和长期保存。

## 2. 目标用户与使用边界

### 2.1 第一版目标用户

- 单个班主任
- 管理一个当前班级
- 需要查看历届归档班级
- 使用 Windows 10/11
- 使用 Microsoft Edge 或 Google Chrome

### 2.2 第一版不包含

- 多人协作
- 云端账号与跨设备同步
- 学校级管理员后台
- macOS 和 Linux 适配
- 小程序和移动端原生界面
- 数据库密码或应用启动密码

## 3. 核心原则

### 3.1 本地优先

所有业务数据默认保存在用户电脑，不依赖互联网和远程服务。

### 3.2 数据可迁移

数据库、附件、导入文件、导出文件和备份都位于工作台目录内。目录移动后，附件引用仍然有效。

### 3.3 接口优先

Web 前端不直接访问 SQLite、Windows 路径或本地文件系统。所有数据和文件操作统一通过业务接口完成，为服务器版、桌面端和小程序预留稳定边界。

### 3.4 模块通用

产品面向小学、初中、高中和职业教育。系统提供稳定的核心字段、自定义字段以及模块启停能力，不针对单一学段写死业务结构。

### 3.5 数据安全优先

导入、删除、迁移和升级等高风险操作必须可预览、可回滚、可恢复。真实学生数据不得进入 Git 仓库。

## 4. 产品阶段

### 4.1 第一阶段：班级基础底座

- 创建和维护当前班级
- 学生信息管理
- 自定义字段
- Excel、JSON、CSV 批量导入
- 网页增删改和批量调整
- 学生头像与附件
- 查询、筛选和排序
- 基础名单打印
- Excel、JSON、CSV 数据导出
- SQLite 完整备份
- 班级归档与历史查看
- 操作记录、备份与恢复

### 4.2 第二阶段：班务组织工具

- 座位表与自由排座
- 学生分组
- 班委名单
- 值日安排
- 常用名单与目录
- 座位表、值日表和班委表打印

### 4.3 第三阶段：日常记录工作台

- 考勤与请假
- 待办与提醒
- 奖惩和行为记录
- 学生谈话记录
- 家校沟通记录
- 成绩和成长变化
- 班级统计与阶段总结

## 5. 长期演进

### 5.1 Windows 桌面端

复用 React 页面、业务模型和接口，通过桌面容器提供独立窗口、系统托盘和自动升级。

### 5.2 服务器 Web 端

将 Go 服务部署到服务器，增加用户、学校、权限、审计和多租户能力。数据规模扩大后可将 SQLite 替换为 PostgreSQL。

### 5.3 小程序端

小程序界面独立实现，复用业务规则、字段定义、数据结构和服务器 API。

### 5.4 移动端

根据使用场景选择响应式 Web、PWA 或原生客户端，不让移动端约束反向增加第一版复杂度。

## 6. 工作台目录规划

```text
ClassPilot/
├─ ClassPilot.exe
├─ data/
│  └─ classpilot.sqlite
├─ attachments/
├─ imports/
├─ exports/
├─ backups/
└─ logs/
```

发布程序可以内嵌 Web 静态资源。业务数据始终保存在外部目录，升级程序不得覆盖业务数据。

## 7. 版本与文档流程

1. 需求讨论并确认设计。
2. 编写设计规格并由用户评审。
3. 编写实施计划并由用户评审。
4. 按计划分阶段编码和验证。
5. 使用中文 Git 提交信息提交变更。
6. 推送 GitHub 作为源码和文档备份。
